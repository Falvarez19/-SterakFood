PARA APLICARLO
1. Hacer una copia de seguridad del proyecto principal.
2. Copiar el contenido de este ZIP encima de la raiz del proyecto SterakFood.
3. NO reemplazar tu .env ni tu db.sqlite3.
4. Ejecutar:
   python manage.py migrate
   python manage.py check
   python manage.py runserver
